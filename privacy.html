VideosHilarios · Automação TikTok

Política de Privacidade

Última atualização: 29 de agosto de 2026

Esta é uma ferramenta pessoal de automação, não um serviço voltado ao público. Ela existe para processar e publicar vídeos — de conteúdo próprio ou expressamente autorizado por seus criadores — no perfil de uma única conta do TikTok controlada por seu operador.

01

O que esta aplicação acessa

Ao autorizar o aplicativo pela tela de login do TikTok, a aplicação recebe apenas:

  • Um token de acesso OAuth, usado exclusivamente para publicar vídeos na conta que o concedeu;
  • Informações básicas de perfil (nome de exibição, ID público, foto) — o mínimo exigido pela própria API do TikTok para autenticação.
02

O que não coletamos

A aplicação não coleta, rastreia ou armazena dados de nenhum outro usuário do TikTok. Não usa cookies de rastreamento, pixels ou analytics de terceiros. Não existe uma base de usuários — há apenas o operador e a conta que ele mesmo autorizou.

03

Onde os dados ficam

Todas as credenciais (token de acesso, chaves de API) são armazenadas localmente, num arquivo de configuração na máquina do operador. Não há servidor remoto, banco de dados na nuvem ou backend de terceiros envolvido no armazenamento dessas informações.

04

Compartilhamento com terceiros

Nenhum dado é vendido, alugado ou compartilhado com terceiros. A única comunicação externa que a aplicação faz é com os endpoints oficiais da API do TikTok, exclusivamente para publicar o conteúdo que o operador preparou.

05

Retenção e revogação

O token de acesso é mantido apenas enquanto a automação estiver em uso ativo. A conta autorizada pode revogar o acesso a qualquer momento em Configurações do TikTok → Segurança → Apps e sites conectados, o que invalida o token imediatamente.
