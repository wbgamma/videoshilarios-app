VideosHilarios
Aplicativo de desktop · Automação pessoal

Uma esteira pessoal para publicar vídeo no TikTok, sem abrir o app toda vez.

Ferramenta de linha de comando (CLI), em Python, que baixa, converte para 9:16 e publica vídeos no perfil do próprio operador — usando a API oficial do TikTok, com autorização OAuth explícita da conta.

01

O app rodando de verdade

Não existe interface web — o produto é o terminal. As duas capturas abaixo são da execução real do fluxo de demonstração enviado na auditoria: início do roteiro guiado e uma publicação chegando a PUBLISH_COMPLETE via Content Posting API.

02

Como o pipeline funciona

Cinco comandos cobrem o ciclo inteiro, do conteúdo bruto até o post publicado.

# 1. baixar / ingerir conteúdo (fonte de stock ou repost autorizado) $ python main.py fetch --source pexels --category "funny animals" # 2. converter para 9:16 + gerar thumbnail (FFmpeg) $ python main.py process # 3. autorizar a conta (OAuth 2.0 + PKCE) — uma vez só $ python main.py tiktok-login # 4. publicar direto no perfil, via Content Posting API $ python main.py publish --platform tiktok
03

Recursos

Deduplicação hash + id

Cada vídeo é identificado por hash de arquivo e id de origem — rodar o mesmo fetch duas vezes nunca baixa duplicado.

Conversão 9:16 FFmpeg

Letterbox automático, normalização de áudio e geração de thumbnail para cada item processado.

Login OAuth PKCE + refresh

Autorização via navegador local (localhost:8000/callback); o token renova sozinho quando expira.

Direct Post video.publish

Publica direto no perfil autorizado e acompanha o status até a confirmação da API.

Rascunho video.upload

Alternativa que envia para a caixa de entrada do criador, que finaliza a publicação no próprio app.

Fila com estado SQLite

Cada item percorre estados (baixado → pronto → agendado → publicado) rastreáveis em banco local.

Política de Privacidade Termos de Serviço Código-fonte

VideosHilarios é uma ferramenta de uso pessoal — não há cadastro de terceiros nem contas de outros usuários envolvidas. Roda inteiramente na máquina do operador; nenhum dado é enviado a servidores próprios.
